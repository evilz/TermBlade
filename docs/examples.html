Repository examples

Start from working code, not a blank terminal.

Every command below maps to an existing project or sample. Use the Core samples to explore low-level rendering, Razor samples to build component UIs, and complete applications to study real structure.

TermBlade.Core samples

Imperative rendering examples

Layout · colors · borders

Layout and styled text

Draw boxes, text, and terminal styling directly through the core rendering API.

dotnet run --project samples/TermBlade.Samples -- layout

Editing · undo/redo

Editor

Explore the rope-backed edit buffer and interactive editor behavior.

dotnet run --project samples/TermBlade.Samples -- editor

Input · focus

Input and keypress

Inspect text input handling and normalized key events.

dotnet run --project samples/TermBlade.Samples -- input dotnet run --project samples/TermBlade.Samples -- keypress

Rendering

Frame buffer, Markdown, Diff

See pixel-style drawing, rich text rendering, and a side-by-side diff.

dotnet run --project samples/TermBlade.Samples -- framebuffer dotnet run --project samples/TermBlade.Samples -- markdown dotnet run --project samples/TermBlade.Samples -- diff

Controls

Select, slider, tabs, tree

Run interactive selection and navigation controls.

dotnet run --project samples/TermBlade.Samples -- select dotnet run --project samples/TermBlade.Samples -- slider dotnet run --project samples/TermBlade.Samples -- tabs dotnet run --project samples/TermBlade.Samples -- treeview

Visuals

ASCII, code, console, showcase

Try art rendering, syntax formatting, console overlay, and the larger showcase.

dotnet run --project samples/TermBlade.Samples -- ascii dotnet run --project samples/TermBlade.Samples -- code dotnet run --project samples/TermBlade.Samples -- console dotnet run --project samples/TermBlade.Samples -- nova

TermBlade.Razor samples

Component-hosted examples

All Core sample themes also have Razor-hosted equivalents, plus calendar and chess. Pass one of the following names to the Razor sample project: layout, styled, editor, scroll, input, keypress, ascii, framebuffer, code, markdown, diff, select, slider, tabs, console, treeview, calendar, or chess.

Example
dotnet run --project samples/TermBlade.Razor.Samples -- calendar

Complete applications

Explore a full terminal UI

All components · source viewer

Interactive gallery

Browse every Razor component in a terminal UI with its embedded source code.

dotnet run --project samples/TermBlade.Gallery

Board game · mouse · bot

Chess

A complete Razor terminal application with a board, move history, and controls.

dotnet run --project src/TermBlade.Chess

Packable dotnet tools

Install the real applications

Files · preview · commands

File Manager

Multi-panel file navigation with previews, clipboard operations, and confirmations.

dotnet tool install --global TermBlade.FileManager tbfm ./src

CSV · table · scrolling

CSV Viewer

A less-like viewer for delimited data, powered by the Razor Table component.

dotnet tool install --global TermBlade.CsvViewer tbcsv ./data.csv
